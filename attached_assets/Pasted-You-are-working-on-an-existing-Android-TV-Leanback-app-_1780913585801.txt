DESIGN BASELINE
- Reference resolution: 1920x1080 px, which Android TV treats as 960x540 dp (1dp ≈ 2px).
- Use ONLY dp for sizes/spacing and sp for text. Never hardcode px.
- Define all values as dimension resources in res/values/dimens.xml and reference them
  from XML. Do not inline magic numbers.

OVERSCAN SAFE AREA (mandatory)
- Horizontal margin from screen edges: 48dp
- Vertical margin from screen edges: 27dp
- The banner sits at the bottom, so it must have 27dp margin from the bottom edge and
  48dp from left and right edges. Content must never touch screen edges.

BANNER CONTAINER
- Anchored to bottom, full available width inside safe area (≈ 864dp wide).
- Height: bottom 18–25% of screen → target 120dp (range 110–135dp). Use 120dp.
- This is a SINGLE-ROW info banner: NO horizontal card list, NO scrolling, NO grid.
- Background: vertical gradient, opaque black ~80% at the bottom fading to transparent
  at the top, so text stays readable over live video.

CONTENT LAYOUT (left to right, single row)
- Channel number + channel logo on the left.
  - Logo target box: 64dp x 64dp.
  - Channel number text: 20sp, bold.
- Middle/main column:
  - Current program title: 24sp, bold, max 1 line with ellipsize=end.
  - Time range + "Now" label (e.g. "20:00 – 21:00 • Now"): 16sp.
  - Progress bar showing elapsed time of current program: height 4–6dp (use 4dp),

- "Next" info: e.g. "Next: <program name>" at 14–16sp (use 16sp), single line, ellipsized.

TYPOGRAPHY RULES
- Minimum text size anywhere in this banner is 12sp. Nothing smaller.
- Keep existing fonts/colors unless they break contrast over the gradient.

BEHAVIOR — DO NOT BREAK
- Keep the existing auto-appear-on-channel-change behavior.
