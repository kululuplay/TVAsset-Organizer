---
name: Native Android build limitation
description: Why the IptvPlayer/ Android project is generated but never compiled here
---

This project (`IptvPlayer/`) is a native Android TV app (Kotlin + Gradle + libVLC + Media3).

The Replit environment has no Android SDK, Gradle Android toolchain, NDK, or emulator, and cannot attach libVLC native `.so` libs. So we **generate source code as a downloadable deliverable** — the user builds the APK in Android Studio on their own machine.

**How to apply:** Do not attempt to run/compile/test the Android project here. Focus on code correctness by review, not by build. The user opens the project in Android Studio; the Gradle wrapper jar/`gradlew` scripts are regenerated by Android Studio (we only ship `gradle-wrapper.properties`).

Stack decisions for this app (confirmed with user): ExoPlayer (Media3) is the **primary** engine, libVLC is the **fallback**; PlayerMode = Auto/ExoPlayer/VLC. minSdk 21. Structured for later: EPG, VOD, Series, TMDB, remote config, forced update, speed test, multi-language/RTL.
