Kululu IPTV 1.5.96 updates the playback engines and requires Android 6.0 or newer.

- Media3 ExoPlayer is updated to 1.11.1 and LibVLC to the stable 3.7.6 release.
- The FFmpeg audio decoder extension is rebuilt for the matching Media3 version and all four supported processor architectures.
- Existing startup, rebuffering and memory limits are retained with the updated playback APIs.
- Accounts, favorites, settings and viewing progress are preserved; the application database schema is unchanged.
- Live TV and radio remain TS/MPEG-TS only. Movies and episodes keep their original file formats.
- Playback diagnostics, support reports and movie refresh feedback from 1.5.95 remain available.

Android 6.0 or newer (API 23). Universal APK with ARM 32/64-bit and x86 32/64-bit support. Production package: `com.iptv.player`; version code: `140`.

Validation: 959 Android unit tests, lint and debug/optimized APK compilation passed for the playback upgrade. Physical-device playback has not yet been revalidated with these new library versions; compatibility and smooth playback still depend on the device, media and connection.
