Kululu IPTV 1.5.89 restores visible update controls and improves playback recovery on Android TVs and sticks.

- Settings now includes a direct App-Updates panel with the installed version, update availability and a manual check button.
- An account expiry notice no longer suppresses the update prompt. Update checks stop cleanly when you leave the screen.
- Live TV startup and recovery have bounded timeouts, preventing an endless loading screen. Failed attempts release playback resources and allow a fresh retry.
- Movies and episodes use a smaller encoded-data buffer on older or memory-constrained devices, reducing memory pressure while keeping startup and rebuffering responsive.
- Login, favorites, settings and viewing progress are preserved. Live TV and radio remain TS/MPEG-TS only; HLS stays disabled and movies and episodes retain their native file formats.

Validation: 651 Android unit tests passed with no failures, and Android lint reported no errors. The debug APK was checked for Android 5.0+ support and native playback libraries for all four supported architectures. Model-specific physical playback testing of these changes remains pending; this release does not guarantee support for every codec or device.

Android 5.0 or newer. Universal APK with ARM 32/64-bit and x86 32/64-bit support. Package: `com.iptv.player`; version code: `133`. The release workflow verifies the production signature and upgrade compatibility before publishing, then enables in-app distribution for all users.
